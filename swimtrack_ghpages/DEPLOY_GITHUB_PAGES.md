# SwimTrack – GitHub Pages Deployment

## Was du am Ende hast
Eine kostenlose Web-Adresse wie:
`https://DEIN-USERNAME.github.io/swimtrack`

Deine Tochter öffnet diese URL in Chrome auf dem Samsung XCover 7
und installiert SwimTrack als App auf dem Homescreen.

---

## Voraussetzung
Du hast bereits ein GitHub-Konto und das `swimtrack`-Repository.
Falls nicht: → https://github.com → „Sign up"

---

## Schritt 1 – Dateien auf GitHub hochladen

1. Gehe zu deinem Repository:
   `https://github.com/DEIN-USERNAME/swimtrack`

2. Klicke auf **„Add file"** → **„Upload files"**

3. Ziehe **alle Dateien** aus dem `swimtrack_ghpages`-Ordner hinein:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `.nojekyll`
   - Den ganzen `icons`-Ordner

   ⚠️ **Wichtig:** Den `icons`-Ordner als Ordner hochladen, nicht nur die Dateien!
   → Klicke auf „choose your files" → navigiere in den `icons`-Ordner → alle PNGs auswählen
   → GitHub erstellt den Ordner automatisch

4. Unten auf **„Commit changes"** klicken

---

## Schritt 2 – GitHub Pages aktivieren

1. Im Repository oben auf **„Settings"** klicken
   (das Zahnrad-Symbol ganz rechts in der Menüleiste)

2. Links in der Seitenleiste auf **„Pages"** klicken

3. Unter **„Source"**:
   - Branch: **`main`** auswählen
   - Ordner: **`/ (root)`** auswählen
   - Klicke **„Save"**

4. Warte 1–2 Minuten

5. Oben erscheint eine grüne Box mit deiner URL:
   `https://DEIN-USERNAME.github.io/swimtrack`

---

## Schritt 3 – App auf dem Samsung XCover 7 installieren

1. **Chrome** auf dem Handy öffnen
2. Die GitHub-Pages-URL eingeben:
   `https://DEIN-USERNAME.github.io/swimtrack`
3. SwimTrack öffnet sich vollständig
4. Oben rechts auf die **drei Punkte** ⋮ tippen
5. **„App installieren"** tippen
6. **„Installieren"** bestätigen

✅ **Fertig!** SwimTrack ist als echte App installiert –
mit eigenem Icon 🏊, ohne Browser-Leiste, im Vollbild.

---

## Kosten
**Komplett kostenlos** – GitHub Pages ist für öffentliche und
private Repositories kostenlos verfügbar.

---

## Wichtige Hinweise

- ✅ Alle Daten bleiben auf dem Handy (IndexedDB)
- ✅ Funktioniert offline nach dem ersten Laden
- ✅ Keine Kreditkarte nötig
- ✅ Keine monatlichen Kosten
- ⚠️ Die URL ist öffentlich zugänglich – aber ohne Login
  kommt niemand an die Daten (die liegen nur auf dem Handy)
