# Stage 10.3 – vollständiger Export

- JSON-Gesamtexport enthält Profil, alle Trainings, Wettkämpfe mit allen Starts/Splits/Endzeiten, PBs, Punkteprotokoll und Badges.
- CSV-Export lädt zwei Excel-kompatible UTF-8-Dateien mit Semikolon-Trennung herunter: Training und Wettkämpfe.
- Wettkampf-CSV enthält eine Zeile pro Start sowie dynamische Spalten für jede vorkommende Splitdistanz, Endzeit, Hundertstelwerte, Platz und PB-Kennzeichnung.
